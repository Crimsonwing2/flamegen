# flamegen
## Description
Mod of clangen that aims to change the cats to Wings of Fire dragons.
### Plans
- The ten dragon species and a unique naming system for each
- New conditions (ex: powers like flamescales, future vision, animus, etc. or dragon-specific injuries like missing wings) 
- Rewrites to all text
- Redrawn versions of sprites and art
- New events
- And more!
### Progress
Nothing yet. I'm working on it!! For the first update, expect a basic species and naming system.
